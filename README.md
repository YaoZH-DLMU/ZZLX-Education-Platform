#
本平台以"以学生为中心"的主动学习理念为核心，依托数字化手段将课前自学、课中互动、课后反思与同伴互评融为一体，构建了一个覆盖完整学习闭环的智能教学支撑系统。  
平台定位与设计理念  传统课堂往往以教师讲授为主，学生较为被动。**致知力行平台**的设计出发点是：让每一位学生真正成为学习的主体——他们不仅是知识的接受者，更是知识的讲解者、评价者和探讨者。  平台围绕三个核心问题展开： 
- **学生是否"真的学懂了"？** → 通过视频讲解+互评量化衡量
- **同学之间能否相互促进？** → 通过朋辈互评、打擂和论坛实现
- **老师能否实时感知课堂状态？** → 通过签到词云和课堂互动工具实现

## 一、平台概览

### 1.1 平台定位

致知力行平台是一个面向大学力学课程（材料力学、理论力学、工程力学、航海力学）的智慧教学交互平台，核心设计理念是 **PBL（项目式学习）+ 过程性评价**：

- **朋辈助力**：学生录制讲题视频，互相评分讨论
- **翻转课堂**：课堂案例视频存档与答辩
- **课堂互动**：词云签到 + PPT 实时互动 + 语音录入
- **数据分析**：情感变化曲线 + 积分分布 + 成绩统计

### 1.2 四门课程

| 课程 | 入口地址 | 说明 |
|------|----------|------|
| 材料力学 | https://solitons.top/ZZLX/ | 主课程，数据最全 |
| 理论力学 | https://solitons.top/LLLX/ | 含静力学、运动学、动力学 |
| 工程力学 | https://solitons.top/GCLX/ | 含静力学、材料力学基本变形等 |
| 航海力学 | https://solitons.top/HHLX/ | 简版工程力学，共享知识图谱 |

打开 https://solitons.top 可看到课程选择页面，点击对应课程进入。

### 1.3 账号类型

| 类型 | 学号范围 | 权限 |
|------|----------|------|
| 管理员（教师） | 全部功能 + 课程管理后台 |
| 助教 | 202601-202610 | 可浏览教师页面，不能写入 |
| 学生 | 8-12 位数字学号 | 上传视频、评分、评论、签到、互动 |

## 三、学生功能说明

### 3.1 上传作业视频

1. 点击页面右上角「上传作业视频」
2. 选择科目（材料力学可选理论力学/材料力学，其他课程自动固化）
3. 选择章节和题号
4. 选择视频文件（支持 mp4/webm/ogg）
5. 点击「上传」

上传后系统自动：
- 用 ffmpeg 截取封面缩略图
- 夜间自动转译语音为文字
- AI 评分（7-9 分制）
- 生成随机检查点（用于有意义回复校验）

### 3.2 观看视频与评论

- 视频按章节分类展示
- 可评分（1-10 分）、收藏、评论
- 评论需 20 个以上汉字才被判定为"有意义"
- 系统追踪观看行为（1x 速率实际观看区间）

### 3.3 知识图谱

- 点击导航栏「力学笃行」
- 可视化展示知识点之间的关联
- 点击节点查看详情和慕课视频
- 教师可为知识点上传慕课视频

### 3.4 论坛

- 分为「智慧学习」「案例分析」「力学畅想」三个板块
- 可发帖、回复、点赞、上传图片
- AI 自动判断回复质量（有意义/无意义）

### 3.5 个人空间

- 头像上传、个人简介、背景色
- 星级展示（1-5 星，基于视频/评论/收藏/帖子等综合计算）
- 三属性雷达图（攻击/防御/魔力）
- 我的视频 / 收藏 / 帖子 / 通知

### 3.6 卡牌对战

- 上传视频后自动生成技能卡
- 选择 3 张卡加入对战池
- 攻击其他学生，三角克制（近战 > 魔法 > 远程 > 近战）
- 每日最多 5 次攻击，连胜加成积分

## 四、教师功能说明

### 4.1 词云签到

**创建签到**：
1. 进入「课程管理」->「词云签到」标签页
2. 点击「创建签到会话」
3. 输入签到问题（如"请用一个词描述今天的学习收获"）
4. 生成二维码，学生扫码答题

**签到关闭时自动**：
- 导出词云 Markdown 报告 + PNG 截图
- 每个签到学生 +0.5 积分
- 统计 HTML 互动页参与（+0.2/页）
- 触发情感曲线 AI 分析（需手动点击）

### 4.2 PPT 课堂互动

**课前准备**：
1. 进入「课程管理」->「课堂PPT」标签页
2. 创建课件会话
3. 上传幻灯片（图片/视频/HTML 代码页）
4. 调整顺序

**课堂演示**：
1. 点击「演示」进入全屏演示页
2. 键盘 ←/→ 或空格翻页
3. 点击「选择题/投票/简答」开始互动
4. 可使用语音录入（说出内容，AI 自动整理为题目）
5. 学生扫码参与互动

**语音录入操作**：
1. 点击「选择题」/「投票」/「简答」按钮
2. 对着麦克风说出题目内容
3. 说出"结束"或等待倒计时结束
4. AI 自动整理为结构化题目，可手动修改
5. 点击「立即发布」或等待 3 秒自动发布
6. **点击「取消」可立即停止录音并关闭弹窗**

**结束课堂时**：
- 自动召回全部未屏蔽互动
- 教师选择正确答案
- 按答题速度排名发分（前 10 名梯度加分）
- 答对学生额外 +1 分

### 4.3 互动管理（屏蔽与删除）

在 PPT 管理页面，每个有互动的课件显示「💬 互动(N)」按钮：
- 点击展开悬浮窗，列出每个互动的类型、主题、回答数
- 「屏蔽」：该互动不参与结束积分召回（可恢复）
- 「删除」：删除互动及其回答（不影响已发积分）

### 4.4 下课结算

进入「课程管理」->「数据分析」->「执行积分结算」：

自动结算内容：
1. **签到积分**：每个签到学生 +0.5
2. **互动参与积分**：参与基础分 + 排名加分 + 答对加分
3. **HTML 互动页参与**：+0.2/页
4. **有意义回复统计**：三重否决判定（观看+时限+语义）

积分结算为后台异步执行，完成后自动更新回复统计。

### 4.5 意义回复三重否决

仅针对**作业视频评论**（论坛回复不受影响）：

| 否决点 | 条件 | reject_reason |
|--------|------|---------------|
| 观看否决 | 未观看检查点（1x 速率覆盖 ±5s 窗口） | watch |
| 时限否决 | 评论不在观看后 10 分钟内 | temporal |
| 语义否决 | AI 判定与视频内容完全无关 | semantic |

三关全过 + AI 质量判定通过 = 有意义回复。

## 五、课程管理后台

### 5.1 数据管理

- 导出课堂互动记录（JSON，已过滤屏蔽项）
- 导出签到记录（JSON）
- 导出学生积分快照（JSON）
- 导出视频作业成绩（JSON）
- 导出有意义回复（JSON）

### 5.2 数据分析

- **积分快照**：三色柱状图，按积分区间显示人数分布，三周/月对比，左右翻页
- **读入分析数据**：支持从本地读入 JSON 文件预览

### 5.3 过程化考核成绩

```
过程化考核成绩 = min(成绩上限, 星级系数 × (视频作业成绩 + 有意义回复分数 + ⌊积分/兑换系数⌋))
```

教师可配置成绩上限、星级系数、兑换系数。

### 5.4 精选归档

学期结束后执行，保留打擂最高分，清理其他数据，为新学期初始化。

## 六、情感变化曲线分析

### 6.1 四个维度

| 维度 | 含义 | 高分 | 低分 |
|------|------|------|------|
| 改革接受度 | 对教学改革的认同 | "有用""收获" | "没用""快逃" |
| 兴趣参与度 | 学习兴趣和参与 | "有趣""新鲜" | "无聊""困" |
| 负担阻抗感 | 负担+抗拒（不是越高越好）| "麻烦""不如纸质" | "轻松""简单" |
| 自主选择认同度 | 自主学习认同 | "自学""自律" | "被动""依赖" |

### 6.2 使用方法

1. 进入「课程管理」->「数据分析」
2. 最上方为「从观望到参与：课堂改革中的学生情感变化曲线」框
3. 点击「📊 分析」按钮触发 AI 全量分析（需 10-30 秒）
4. SVG 四线图展示各签到节点的四维分数变化
5. 点击图例可切换显示/隐藏某条线
6. 点击「展开分析数据」查看每次签到的详细分数和摘要

### 6.3 管理签到数据

点击「⚙️ 管理签到数据」按钮：
- 列出全部有效签到（日期+题目）
- 可取消勾选排除某些签到（如测试签到）
- 点击「重新分析」用排除后的数据重新打分

### 6.4 有效签到判定

- 参与学号 ≥10 名 8 位以上数字学号
- 签到问题含课程相关关键词
- 自动排除 AI 讨论、假期收获等非课程话题

## 八、多课程说明

### 8.1 课程独立隔离

每门课程有完全独立的：
- 数据库（学生、视频、签到、积分等）
- 学生名单
- 知识图谱 / 问题图谱
- 上传文件目录
- AI 助手人格
- 论坛板块

### 8.2 课程差异配置

| 配置项 | 材料力学 | 理论力学 | 工程力学 | 航海力学 |
|--------|----------|----------|----------|----------|
| 作业章节 | 2-10,13 | 1-14 | 1-13 | 1-13 |
| 上传科目 | 理论力学/材料力学 | 固化理论力学 | 无科目选择 | 无科目选择 |
| 翻转案例 | 双臂立卷夹钳/翻车机 | 同材料力学 | 工程案例1/2 | 航海案例1/2 |
| 知识图谱 | 独立 | 独立 | 独立 | 共享工程力学 |
| 视频标题 | 材料力学X章X题 | 理论力学X章X题 | 工程力学X章X题 | 航海力学X章X题 |

### 8.3 新增课程步骤

1. 在 `app/courses.py` 添加课程配置
2. 在 `config.py` 的 `SQLALCHEMY_BINDS` 添加数据库
3. 在 `docker-compose.yml` 添加 KG/QG 文件挂载
4. 在 `nginx.conf` 添加课程 location
5. 重启容器（自动建表+播种教师）
6. 准备 KG.json / QG.json / StudentList 文件

## 九、平台迁移指南

### 9.1 服务器要求

- Linux 服务器（Ubuntu 22.04+）
- Docker + Docker Compose
- 80/443 端口
- HTTPS 证书（Let's Encrypt）

### 9.2 迁移步骤

#### 步骤 1：备份原服务器

```bash
# 备份数据库
docker compose exec web cp /app/db/zzlx.db /app/db/zzlx.db.backup

# 备份上传文件
docker run --rm -v zzlx_uploads:/data -v /backup:/out alpine tar czf /out/uploads.tar.gz -C /data .

# 备份代码和配置
tar czf /backup/zzlx_code.tar.gz app/ config.py run.py docker-compose.yml nginx/ KG.json QG.json
```

#### 步骤 2：新服务器初始化

```bash
# 安装 Docker
curl -fsSL https://get.docker.com | sh

# 创建项目目录
mkdir -p /opt/ZZLXWeb/db
cd /opt/ZZLXWeb

# 传输代码和配置
scp zzlx_code.tar.gz root@新服务器:/opt/ZZLXWeb/
tar xzf zzlx_code.tar.gz

# 传输数据库
scp zzlx.db root@新服务器:/opt/ZZLXWeb/db/zzlx.db

# 传输上传文件
docker run --rm -v zzlx_uploads:/data -v /opt/ZZLXWeb/app/static/uploads:/out alpine tar xzf /out/uploads.tar.gz -C /data
```

#### 步骤 3：修改配置

**docker-compose.yml**：
- 修改 `SECRET_KEY` 为新的随机字符串
- 修改 `DEEPSEEK_API_KEY`
- 修改 `ALIYUN_*` 密钥
- 修改 SSL 证书路径

**nginx.conf**：
- 修改 `server_name` 为新域名
- 确认 SSL 证书路径

#### 步骤 4：申请 HTTPS 证书

```bash
# 停 nginx 释放 80 端口
docker compose stop nginx

# 申请证书
certbot certonly --standalone -d 新域名.com

# 复制证书
cp /etc/letsencrypt/live/新域名.com/*.pem /opt/ZZLXWeb/SSL/
mv /opt/ZZLXWeb/SSL/fullchain.pem /opt/ZZLXWeb/SSL/www.新域名.com.pem
mv /opt/ZZLXWeb/SSL/privkey.pem /opt/ZZLXWeb/SSL/www.新域名.com.key

# 启动
docker compose up -d
```

#### 步骤 5：验证

1. 访问 `https://新域名/` -> 落地页显示 4 个课程按钮
2. 点击课程 -> 登录 -> 数据正常
3. 上传视频 -> 正常
4. 签到 -> 正常
5. PPT 演示 -> 正常

### 9.3 新增课程迁移

如需在其他服务器部署新课程：

1. 按 9.2 迁移基础平台
2. 修改 `courses.py`，调整课程前缀和配置
3. 准备该课程的 KG.json / QG.json
4. 准备 StudentList 文件
5. 启动时自动建表 + 播种教师

### 9.4 数据备份与恢复

**定期备份**（建议每周）：
```bash
# 备份 4 个数据库
cd /opt/ZZLXWeb/db
for f in *.db; do cp "$f" "${f}.$(date +%Y%m%d).bak"; done

# 备份上传文件
docker run --rm -v zzlx_uploads:/data -v /backup:/out alpine tar czf /out/uploads_$(date +%Y%m%d).tar.gz -C /data .
```

**恢复**：
```bash
# 停止服务
docker compose stop web

# 恢复数据库
cp /backup/zzlx.db.20260801.bak /opt/ZZLXWeb/db/zzlx.db

# 恢复上传文件
docker run --rm -v zzlx_uploads:/data -v /backup:/out alpine tar xzf /out/uploads_20260801.tar.gz -C /data

# 启动
docker compose start web
```
